# 组件库 m-unix 1.0.0（2026-03-23）

**简述：** 初始版本发布。

## 新增组件

- `m-row` - 栅格行
- `m-col` - 栅格列
- `m-card` - 卡片容器
- `m-cell` - 单元格
- `m-gap` - 占位间距
- `m-bottom-popup` - 底部弹窗
- `m-button` - 按钮
- `m-search` - 搜索框
- `m-upload` - 图片上传
- `m-datetime-picker` - 日期时间选择
- `m-clipboard` - 剪贴板复制
- `m-div` - 分割线
- `m-empty` - 空状态
- `m-loading` - 加载中
- `m-loadmore` - 加载更多
- `m-notice-bar` - 公告栏
- `m-price` - 价格展示
- `m-tag` - 标签
- `m-tree` - 树形结构
- `m-qrcode` - 二维码生成
- `m-screenshot` - 页面截图
- `m-watermark` - 水印
- `m-overlay` - 遮罩层
- `m-popup` - 弹出层
- `m-toast` - 提示框
- `m-countdown` - 倒计时
- `m-grid` - 宫格
- `m-icon` - 图标
- `m-sticky-bottom` - 粘性底部
- `m-wx-login` - 社交平台账号登录

## 新增工具库

- `utils.uts` - 常用工具函数
- `request.uts` - 网络请求封装

## 特性

- 全部自研实现，无第三方依赖
- 专为 UTS + uvue 跨端工程定制
- 所有组件使用 `m-` 独立前缀
- 每个组件独立打包，按需使用
- 适配小程序端、原生 App、浏览器端
